# ECHODESK — Powered by JOT
## PRD + Antigravity Build Pack

This folder contains the product specification and implementation prompts for building ECHODESK, a privacy-first AI productivity workspace powered by JOT.

### Files

- `01_PRD.md` — complete product requirements document
- `02_SYSTEM_ARCHITECTURE.md` — system, data, agent, and device architecture
- `03_PRIVACY_SECURITY.md` — privacy-by-design, threat model, permissions, data lifecycle
- `04_UX_USER_FLOWS.md` — UX rules and end-to-end user journeys
- `05_MVP_SCOPE.md` — hackathon MVP, priorities, non-goals, acceptance criteria
- `06_ANTIGRAVITY_MASTER_PROMPT.md` — master prompt to give Antigravity before implementation
- `07_ANTIGRAVITY_BUILD_PLAN.md` — staged implementation prompts to reduce hallucination/scope creep
- `08_TESTING_ACCEPTANCE.md` — QA, security, privacy, and demo acceptance checklist

## Core positioning

**ECHODESK** is the workspace.

**JOT** is the AI agent inside it.

JOT captures intent, understands context, decides when to act, protects focus, and remembers work-session state.

Core promise:

> **JOT your intent. Less managing. More doing.**

Core philosophy:

> **JOT knows when to act, when to remember, and when to stay out of your way.**

## Critical implementation rule

Do not implement or claim passive surveillance.

The product does not silently inspect a user's laptop, continuously record screens, or continuously upload camera/microphone data. Sensor assistance is explicit, scoped, and privacy-first.
